# 🚀 TeleGravity

> **Deeply control and monitor your Antigravity AI programming agent from Telegram**

`TeleGravity` is a high-performance, low-latency remote control and synchronization suite designed exclusively for the **Antigravity** AI programming assistant. Whether you are traveling, in a meeting, or relaxing, simply open the Telegram client on your mobile device to seamlessly synchronize PC-end AI chats, switch active projects, authorize tool approvals, monitor running terminals, and even capture high-definition screenshots of your workspace!

> [!IMPORTANT]
> Currently, `TeleGravity` **exclusively supports Windows** running **Antigravity 2.0** (or classic IDE equipped with a CDP debug interface). Windows is required to support the process-tree tracking (`taskkill`, PowerShell queries) and automated background script management.

---

## ✨ Core Features

* 📬 **100% Real-Time Conversation Streaming**: Leveraging advanced log tailing, messages generated by the AI agent are captured and streamed to your Telegram client within **0.1 seconds** of completion, ensuring absolute conversation continuity.
* 💭 **Persistent "Typing..." Status**: Solves the classic Telegram API limitation where typing indicators expire after 5 seconds. The bot maintains a **persistent "typing" status** on your phone while the AI is actively generating text, thinking, or running background tools.
* ⚡ **Interactive Approval & Tool Cards**: When the remote AI requests approval to run terminal commands (e.g. `npm run dev`) or apply file modifications, you will instantly receive an interactive approval card in Telegram. Simply tap **[✅ Approve]** or **[❌ Reject]** to dispatch events directly back to your PC via CDP.
* 🤖 **`/details` Intermediate Toggle**: Toggle between viewing or suppressing intermediate agent thoughts and tool calls in real-time. Turn it off for a squeaky-clean chat interface containing only final answers, or turn it on to audit the AI's step-by-step reasoning.
* 📂 **`/project` Project Swapper**: List all available workspaces/projects registered in your PC's Antigravity sidebar, and switch between them with a single click. The bot automatically closes the old project, loads the new one, and re-anchors the log monitoring transparently!
* 🧠 **`/model` Physical Model Switcher**: Provides an inline keyboard listing all supported AI models (Gemini 3.5 Flash/Pro, Claude 3.5 Sonnet/Opus, etc.), allowing you to physically swap the active model on your PC remotely.
* ⏹️ **`/stop` Force Cancel Generation**: If you notice the AI going in the wrong direction, tap `/stop` on your phone to instantly interrupt and cancel active AI thinking and text generation.
* 📸 **`/screenshot` Workspace Capture**: Takes a real-time, high-definition screenshot of the Antigravity application on your desktop, giving you full visual confidence over your active development state.
* 📋 **Automatic Document Sync**: Detects changes to active markdown artifacts (`implementation_plan.md`, `task.md`, `walkthrough.md`) and automatically pushes a rich formatted preview alongside the **raw `.md` files for direct download**.
* 🖥️ **`/terminal` Background Task Manager**: Automatically tail and monitor active background AI tasks (e.g. `task-120`) in real-time. They are displayed in a dedicated second section on your **Pinned Live Dashboard** and can be terminated safely from Telegram via inline buttons.

## 🛠️ Windows Installation & Configuration

### 1. Prerequisites
Ensure your computer has the following installed:
* **Operating System**: Windows (required for system process hooks)
* **Node.js**: v18.0.0 or higher
* **Antigravity**: Version 2.0 (configured to run with remote debugging port enabled)

### 2. Set Up Your Telegram Bot
1. Search for official **`@BotFather`** in Telegram and send the `/newbot` command.
2. Follow the prompts to set your bot's name and username, then copy your unique **`BOT_TOKEN`**.
3. Search for your newly created bot and click `Start` to activate it.
4. Obtain your personal Telegram **`Chat ID`** by messaging a dedicated ID bot (e.g. `@userinfobot`).

### 3. Install and Configure the Project
1. Extract or clone this repository to your local drive.
2. Open a terminal inside the project root directory and install dependencies:
   ```bash
   npm install
   ```
3. Create a `.env` file in the root directory (or duplicate `.env.example`) and fill in your configurations:
   ```env
   # Your Telegram Bot Token
   BOT_TOKEN=your_bot_token_here
   
   # Your Telegram Chat ID (supports multiple IDs separated by commas)
   ALLOWED_CHAT_ID=your_chat_id_here
   
   # CDP Debugging Port (Must match Antigravity's --remote-debugging-port, default is 9223)
   AGENT_CDP_PORT=9223
   ```

### 4. Running the Bot on Windows

#### Method A: VBS Background Scripts (Recommended & Easiest)
We have provided robust VBS scripts to run and stop the bot silently in the background without keeping a command prompt open:
* **To Start the Bot**: Double-click **`启动机器人.vbs`** (Launch Bot). It will automatically check if the CDP port is open, restart Antigravity with debugging enabled if needed, and boot the bot silently.
* **To Stop the Bot**: Double-click **`停止机器人.vbs`** (Stop Bot). It will terminate any running bot processes cleanly.

#### Method B: PM2 Process Daemon (For Developers)
If you prefer standard node management, you can use **PM2** to run the bot silently:
* **Start Service**:
  ```bash
  npx pm2 start src/index.js --name "tg-bot"
  ```
* **List Running Services**:
  ```bash
  npx pm2 list
  ```
* **Restart Service**:
  ```bash
  npx pm2 restart tg-bot
  ```
* **Stop Service**:
  ```bash
  npx pm2 stop tg-bot
  ```
* **View Real-Time Logs**:
  ```bash
  npx pm2 logs tg-bot
  ```

## 🐙 Git Iteration and GitHub Workflow

If you want to save your progress, share the project, or contribute changes back to your GitHub repository, follow this streamlined workflow:

### 📦 Zip Distribution (Excluding Private Data)
When packaging the project as a `.zip` file to send to others, **always ensure you do not leak credentials or duplicate heavy folders**:
1. **Exclude these folders/files**:
   * `node_modules/` (heavy library directory; others should run `npm install` to regenerate)
   * `.env` (contains your private Telegram Bot Token and Chat ID; **never share!**)
   * `bg_out.log` and `bg_err.log` (local process logs)
2. **Zip the rest of the folder** and distribute. The recipient simply needs to run `npm install` and create their own `.env` file to start.

### 🔄 Daily Git Iteration (Standard Workflow)
Once your local repo is initialized and committed, use this classic three-step routine in your root folder whenever you make edits and want to save them on GitHub:

1. **Stage changes**:
   ```powershell
   git add .
   ```
2. **Commit changes**:
   ```powershell
   git commit -m "feat: translate readme and restrict to windows antigravity 2.0"
   ```
3. **Push to GitHub**:
   ```powershell
   git push
   ```
